# ريلز المؤتمر السنوي لتكنولوجيا الفضاء والأقمار الاصطناعية

فيديو Motion Graphics عمودي (Reel) للترويج لـ **المؤتمر السنوي لتكنولوجيا الفضاء والأقمار الاصطناعية — نقابة المهندسين العراقيين**، مبني بالكامل بإطار **[HyperFrames](https://github.com/heygen-com/hyperframes)** (HTML → فيديو، تحريك GSAP قابل للتقديم إطاراً بإطار).

| | |
|---|---|
| المقاس | 1080 × 1920 · 9:16 |
| الإطارات | 30 FPS |
| المدة | **20.00 ثانية بالضبط** (النسخة الأساسية) |
| الخط | DIN Next LT Arabic (الملف المرفق) لكل النصوص العربية والإنجليزية |
| الصوت | ملف الـ Voice Over الأصلي + موسيقى ومؤثرات أصلية مولّدة بالكامل |

## المخرجات (`output/`)

| الملف | المدة | الصوت |
|---|---|---|
| `space-conference-reel_20s.mp4` | 20.00 ث | الـ VO الأصلي، مع تقليص الوقفات وتسريع ×1.186 (مع الحفاظ على طبقة الصوت) ليتّسع في 20 ثانية |
| `space-conference-reel_full-vo.mp4` | 26.00 ث | الـ VO الأصلي **كما هو تماماً** بسرعته الطبيعية |

كلا الملفين: H.264 بمعدل 14 Mbps، صوت AAC 48 kHz، −15 LUFS، والتزامن مُتحقَّق منه (انحراف أقل من 11 ms لكل جملة).

**لماذا نسختان؟** ملف الصوت مدته 24.85 ثانية، منها **22.7 ثانية كلام فعلي** (تحليل VAD)، والوقفات بين الجمل قصيرة جداً (0.15–0.4 ث). لذلك يستحيل وضع الـ VO كاملاً داخل 20 ثانية دون تسريعه. نسخة الـ 20 ثانية تحقق شرط المدة، ونسخة الـ 26 ثانية تحقق شرط «عدم تغيير الصوت». كلتاهما من نفس المشروع ونفس المشاهد، والتوقيت كله محسوب من الصوت نفسه.

## التشغيل

المتطلبات: Node.js 22+، FFmpeg، Python 3 مع `numpy scipy pillow pyloudnorm`.

```bash
# 1) ضع ملف الخط (غير مرفوع للمستودع لأنه خط تجاري):
#    assets/fonts/DINNextLTArabic-Regular.ttf
npm install                 # بيانات الكرة الأرضية (Natural Earth) و d3-geo
npm run build               # يولّد البيانات والخلفيات والـ index.html والموسيقى/المؤثرات
npm run dev                 # معاينة HyperFrames Studio في المتصفح
npm run render:20s          # output/space-conference-reel_20s.mp4  + فحص الجودة
npm run render:full         # output/space-conference-reel_full-vo.mp4 + فحص الجودة
```

> في بيئة بدون Chrome مُثبّت لـ HyperFrames: `export HYPERFRAMES_BROWSER_PATH=/path/to/chrome-headless-shell`.

## التعديل لاحقاً

- **التوقيت**: `src/timing.js` — أوقات كلمات الـ VO وحدود المشاهد. بعد التعديل: `npm run build:audio` ثم إعادة الـ render. كل حركة في المشاهد تُطلب باسم الكلمة (`L("almutamar")`) لذلك تبقى متزامنة.
- **النصوص**: داخل كل مشهد في `compositions/` (عناصر `.ar`).
- **الألوان والمقاسات**: `src/styles/tokens.css`.
- **الشخصية**: `src/components/astronaut.js` — تصميم واحد يُستخدم في كل المشاهد؛ المشاهد تغيّر الوضعية فقط (`rig.set(pose)`).
- **الصوت**: مستوى الموسيقى/المؤثرات في `scripts/build_audio.py` (`LUFS_MUSIC`, `LUFS_SFX`)، والأحداث في `src/audio-plan.js`. بعد الـ render تُطبَّق خطوة Mastering نهائية (`scripts/master_audio.py`: رفع مستوى ثابت + Limiter شفاف إلى −15 LUFS و −1 dBTP، دون إعادة توازن) ثم فحص الجودة `scripts/qa.py`. سلسلة معالجة صوت المعلّق (Rumble cut، Compressor، Limiter) على `<hf-audio-group id="voiceover">` داخل `scripts/build_roots.mjs` — غير مُدمِّرة، والملف الأصلي لا يُمس.
